# 电商平台 - 项目需求说明书

## 项目概述
构建一个全功能的 B2C 电商平台，支持商品浏览、购物车、订单管理和支付功能。

## 用户端功能

### 商品浏览
- 商品分类导航（三级分类）
- 商品搜索（关键词搜索、筛选、排序）
- 商品详情（图片轮播、规格选择、用户评价）

### 购物车
- 添加/删除/修改商品数量
- 商品选中/取消选中
- 价格实时计算
- 库存校验

### 订单流程
1. 确认订单（地址、商品、价格）
2. 选择支付方式
3. 支付（集成第三方支付）
4. 订单确认

### 用户中心
- 个人信息管理
- 收货地址管理
- 订单列表与详情
- 收藏夹
- 浏览历史

## 管理后台功能

### 商品管理
- 商品 CRUD
- 批量上下架
- 库存管理
- 商品规格管理（SKU）

### 订单管理
- 订单列表（筛选、搜索）
- 订单详情
- 发货处理
- 退款处理

### 数据统计
- 销售概览（今日/本周/本月）
- 商品销量排行
- 用户增长趋势
- 营收报表

## 技术栈
- 后端：Python Django REST Framework + PostgreSQL
- 前端：Vue 3 + Element Plus
- 搜索：Elasticsearch
- 缓存：Redis
- 消息队列：RabbitMQ
- 文件存储：阿里云 OSS

## 非功能需求
- 支持 10000+ 商品
- 并发 1000+ 用户
- 首页加载 < 3s
- 订单处理 < 1s
- 数据加密传输
- 日志审计
