开发一个在线任务管理平台（TaskFlow），具体要求如下：

## 核心功能

### 1. 用户系统
- 用户注册：支持邮箱注册，发送验证邮件
- 用户登录：支持邮箱+密码登录，JWT Token 鉴权
- 个人中心：查看/修改个人信息，上传头像
- 密码找回：通过邮箱重置密码

### 2. 任务管理
- 创建任务：标题、描述、优先级（高/中/低）、截止日期、标签
- 任务列表：支持按状态、优先级、截止日期筛选和排序
- 任务详情：展示完整任务信息，支持评论
- 任务编辑：修改任务信息，状态流转（待办→进行中→已完成）
- 任务删除：软删除，支持回收站恢复

### 3. 项目看板
- 看板视图：以卡片形式按状态分类展示任务
- 拖拽操作：支持拖拽卡片改变任务状态
- 泳道视图：按优先级分组展示

### 4. 团队协作
- 团队创建：创建团队空间，邀请成员
- 任务分配：将任务分配给团队成员
- 实时通知：任务状态变更、评论、分配时发送通知
- 活动日志：记录团队空间内所有操作

### 5. 数据统计
- 个人统计：完成任务数、效率趋势图
- 团队统计：成员贡献度、项目进度概览
- 导出功能：支持导出 CSV/Excel 报表

## 技术栈要求
- 后端：Python FastAPI + SQLAlchemy + PostgreSQL
- 前端：React + TypeScript + Ant Design
- 实时通信：WebSocket
- 缓存：Redis

## 非功能需求
- 响应式设计，支持移动端
- API 响应时间 < 200ms
- 支持 1000 并发用户
- 代码测试覆盖率 > 80%
