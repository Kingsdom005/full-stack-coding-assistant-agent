## 1. 项目背景

### 1.1 业务场景
某教育机构需要一个在线考试系统，用于学员的课后测验、阶段考试和结业考核。
系统需支持多种题型、自动评分、成绩分析等功能。

### 1.2 用户角色

| 角色 | 权限说明 |
|------|----------|
| 学员 | 参加考试、查看成绩 |
| 教师 | 创建题库、组卷、阅卷、查看成绩分析 |
| 管理员 | 用户管理、系统配置、数据统计 |

### 1.3 核心目标
- 支持 500 人同时在线考试
- 试卷创建时间 < 5 分钟（自动组卷）
- 客观题自动评分准确率 100%

## 3. 功能需求

### 3.1 题库管理（教师端）

#### 3.1.1 题目类型
- **单选题**: 4个选项，1个正确答案
- **多选题**: 4-6个选项，多个正确答案
- **判断题**: 正确/错误
- **填空题**: 支持多个空，每个空支持等价答案
- **简答题**: 文本回答，人工评分
- **编程题**: 代码提交，自动判题+人工复核

#### 3.1.2 题目管理功能
- 批量导入：支持 Excel/CSV 批量导入题目
- 题目标签：支持自定义标签分类
- 难度等级：简单/中等/困难
- 题目版本：支持修订历史

### 3.2 试卷管理（教师端）

#### 3.2.1 组卷方式
- **手动组卷**: 从题库手动选择题目
- **自动组卷**: 设置题型分布、难度分布、知识点覆盖，系统自动抽取
- **随机组卷**: 从题库随机抽取，每人试卷不同

#### 3.2.2 试卷配置
- 考试时长（分钟）
- 开始/结束时间
- 及格分数线
- 是否允许切屏
- 是否显示成绩

### 3.3 考试功能（学员端）

#### 3.3.1 考试流程
1. 学员登录 → 进入待考列表
2. 点击开始考试 → 倒计时启动
3. 逐题作答 → 支持标记疑难题目
4. 提交试卷 → 确认提交对话框
5. 查看成绩（如开放）→ 查看答案解析

#### 3.3.2 防作弊机制
- 切屏检测（超过3次自动交卷）
- 考试倒计时（时间到自动交卷）
- 答题进度保存（防止断网丢失）

### 3.4 评分系统

| 题型 | 评分方式 |
|------|----------|
| 单选/判断 | 自动评分 |
| 多选 | 自动评分（部分得分） |
| 填空 | 自动评分（等价匹配） |
| 简答 | 人工评分 |
| 编程 | 自动判题 + 人工复核 |

### 3.5 成绩分析

- 个人成绩报告（得分、排名、知识点掌握度）
- 班级成绩统计（平均分、最高分、最低分、及格率）
- 题目分析（正确率、区分度、难度系数）
- 成绩导出（PDF/Excel）

## 4. 数据库设计

### 4.1 核心表结构

```sql
-- 用户表
CREATE TABLE users (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(50) NOT NULL UNIQUE,
    password_hash VARCHAR(255) NOT NULL,
    role ENUM('student', 'teacher', 'admin') NOT NULL,
    email VARCHAR(100),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 题目表
CREATE TABLE questions (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    type ENUM('single', 'multiple', 'judge', 'fill', 'essay', 'code') NOT NULL,
    content JSON NOT NULL COMMENT '题目内容和选项',
    answer JSON NOT NULL COMMENT '正确答案',
    difficulty ENUM('easy', 'medium', 'hard') DEFAULT 'medium',
    tags VARCHAR(500),
    creator_id BIGINT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 试卷表
CREATE TABLE exams (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    title VARCHAR(200) NOT NULL,
    duration INT NOT NULL COMMENT '考试时长(分钟)',
    pass_score DECIMAL(5,2) DEFAULT 60.00,
    start_time TIMESTAMP,
    end_time TIMESTAMP,
    status ENUM('draft', 'published', 'closed') DEFAULT 'draft'
);
```

## 5. 接口规范

### 5.1 RESTful API 设计

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/auth/login | 用户登录 |
| POST | /api/auth/register | 用户注册 |
| GET | /api/exams | 获取考试列表 |
| GET | /api/exams/:id | 获取考试详情 |
| POST | /api/exams/:id/start | 开始考试 |
| POST | /api/exams/:id/submit | 提交答案 |
| GET | /api/results/:id | 获取成绩 |

### 5.2 统一响应格式

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

## 6. 非功能需求

### 6.1 性能指标
- 并发考试人数：500+
- API 响应时间 P99 < 500ms
- 自动判题延迟 < 2s
- 数据库查询优化：关键查询 < 50ms

### 6.2 安全要求
- 密码 bcrypt 加密存储
- JWT Token + Refresh Token 双令牌机制
- 接口频率限制（Rate Limiting）
- SQL 注入和 XSS 防护
- 敏感操作日志审计

### 6.3 可用性
- 系统可用性 99.9%
- 数据每日自动备份
- 支持水平扩展
