# 食堂点餐小程序 - 需求文档

## 一、项目背景
某企业园区员工食堂希望开发一款微信小程序，方便员工提前点餐、减少排队等待时间。

## 二、用户端功能

### 2.1 今日菜单
- 展示当日菜品，包含图片、名称、价格、热量信息
- 支持按口味筛选（辣/不辣）
- 菜品状态：可售/售罄

### 2.2 点餐下单
- 选择菜品加入购物车
- 确认订单（选择取餐时间段）
- 微信支付
- 生成取餐码

### 2.3 我的订单
- 待取餐/已完成/已取消
- 订单详情
- 评价菜品（1-5星 + 文字评价）

## 三、管理端功能（Web后台）

### 3.1 菜品管理
- 每日菜单配置
- 菜品上下架
- 价格和库存管理

### 3.2 订单管理
- 实时接单提醒
- 订单状态流转（待接单→备餐中→待取餐→已完成）
- 订单统计

## 四、技术要求
- 小程序端：原生微信小程序框架
- 管理后台：React + Ant Design Pro
- 后端 API：Python FastAPI
- 数据库：MySQL + Redis
- 支付：微信支付 JSAPI
